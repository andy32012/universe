# 字型

`DroidSansFallbackFull.ttf`：Droid Sans Fallback（Google／Android Open Source Project，Apache License 2.0，可自由再散布）。取自 Godot 4.7.2 編輯器內建的同一份字型（原為 WOFF2；iPad 上顯示成方框，所以用 `tools/woff2_to_ttf.py` 轉成不壓縮的 TrueType，3.6 MB，50,608 個字形），用來顯示中文：iPad 上的 Godot 不會自動借用系統的中文字型，系統字型（SystemFont）也取不到，所以打包在 App 裡。涵蓋遊戲目前用到的 461 個中文字。
