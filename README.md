# 從太陽系到宇宙邊緣

以第一人稱在宇宙中飛行：從太陽系一路到可觀測宇宙的邊界。

整個作品是 `index.html` 一個檔案，不需要安裝任何東西，用瀏覽器打開就能執行。

放在網站上（http 或 https）時，可以從瀏覽器「加到主畫面」安裝。`sw.js` 會把整個作品存一份在裝置上，之後沒有網路也能打開；直接用瀏覽器打開本機檔案時不會用到它。更新 `sw.js` 裡的檔案清單時，記得一起改 `VERSION`。

右上角的「畫質」可以選自動、標準、高、極致。自動會從「高」開始，畫面變卡時自動往下調；高和極致會開啟反鋸齒、讓星雲和星系取樣更多、行星更圓、黑洞的光線追蹤更細。選擇會記在這台裝置上。

## 哪些是真的

- 太陽系：八大行星和冥王星真實的橢圓軌道（包含傾角），以及打開頁面當下的位置；跟完整星曆比對，2000–2050 年間誤差在 0.2° 以內。
- 月球：當下的位置和月相，誤差在 0.1° 以內。
- 各天體的實際尺寸。
- 黑洞：12 個真實的黑洞，位置、質量都是真的（天鵝座 X-1、天鵝座 V404、GRS 1915+105、A0620-00、蓋亞 BH1、蓋亞 BH3、人馬座 A*、M31*、半人馬座 A*、M87*、NGC 4889*、TON 618）。光線是在會自轉的克爾黑洞時空裡一步一步追蹤的：黑影的大小和自轉造成的 D 字形、吸積盤後方被彎到上下的光、朝你轉來那一側較亮較藍、光爬出重力井時的紅移、噴流朝你那一邊特別亮，都是算出來的，不是畫上去的。靠近時，背後整片星空會被彎成光環；自轉會拖著空間轉，把你一起帶著繞圈（參考系拖曳），畫面也會顯示你的時間比遠方慢多少。
  - 發光的物質依各黑洞的狀態而不同：吃得快的（天鵝座 X-1、天鵝座 V404、GRS 1915+105、TON 618）是又薄又密的吸積盤，顏色和亮度由盤面溫度決定，用普朗克定律與人眼的色彩匹配函數積分算出，所以會是藍白色；吃得很少的（人馬座 A*、M87*、M31*、半人馬座 A*、A0620-00）是稀薄、透光的熱氣流，看起來像事件視界望遠鏡拍到的光環；沉睡的（蓋亞 BH1、BH3、NGC 4889*）周圍什麼都不發光，只看得到被彎曲的星空。
  - 時間經過調整：伴星繞黑洞的速度是實際的 3,600 倍（一秒等於一小時）。黑洞附近的變化則依各自的質量決定快慢：真實的時間尺度從萬分之一秒（恆星級）到好幾天（超大質量）都有，差距大到無法照實呈現，所以壓縮成小黑洞轉得較快、巨大黑洞轉得較慢。
  - 自轉快慢和轉軸方向，有量測值的用量測值，沒有的是合理的假設。
- 海王星：可以從太空一路飛進雲海，再回到大氣外。靠近時海王星改用體積算繪，遠看的條紋和近看的雲團是同一批雲；飛行速度隨雲頂上方的高度放慢，「比例」切換時你和海王星的相對位置不變（放大只影響畫面，高度、氣壓、溫度永遠是真實值）。
  - 大氣是依 Voyager 2 無線電掩星的溫度剖面（Lindal 1992）用靜力平衡積分出來的；2 bar 以下沒有量測，改用乾絕熱線外推。目前到 10 bar 為止。
  - 雲層由上到下：平流層霧靄、高空甲烷冰雲（約 0.2–0.5 bar）、主甲烷雲層（約 1.2–1.6 bar）、硫化氫雲層（約 3–7 bar）。各層的來源與可信度會在「探測視覺」裡顯示，越深越不確定，硫化氫雲層是模型推論。
  - 風速依 Sromovsky 等人（1993）擬合的緯度風剖面，赤道向西約 400 m/s；雲團隨風飄移，雲頂以上風速較弱。
  - 光線：陽光被氣體的瑞利散射和甲烷吸收（紅光先被吃掉，所以越深越藍綠），雲彼此投下陰影，雲團的背光面落在自己的影子裡；進入雲層後星空和太陽會被遮住，曝光像眼睛一樣慢慢適應，最多亮 40 倍，深處仍是暗的。
  - 「探測視覺」是假色：顏色代表溫度，細線是每四分之一個數量級的等壓面，條紋是風。
  - 天氣時間：從太空看時是實際的 60 倍，進到雲裡逐漸放慢到實際速度，倍率顯示在畫面上。雲的細部形狀是固定亂數種子生成的，大尺度的亮帶依真實貼圖分布，不是某一天的實際天氣。
- 16,166 顆恆星的三維位置與亮度。
- 有名字的星雲、星系、星系團、黑洞的方向與距離（部分座標為近似值）。

其餘的恆星、旋臂上未命名的星雲、宇宙網，是依照真實的分布規律生成的。
