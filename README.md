# 從太陽系到宇宙邊緣

以第一人稱在宇宙中飛行：從太陽系一路到可觀測宇宙的邊界。

主程式、星表、表面影像與音樂程式都在 `index.html`，月球及火星實測地形另放在 `assets/`，按需下載。透過 GitHub Pages 等靜態網站直接開啟，不需安裝套件。直接以 `file://` 開啟時，瀏覽器可能阻擋地形下載，仍可使用程序地形探索。

## 探索方式

- 天體本體和距離採用同一實際比例，不放大行星、恆星或衛星。遠處的光點是未解析的光源或位置標記，不代表天體直徑。
- 從近地球視角開始。使用「探索」搜尋天體，再選擇飛抵、跟隨或環繞；也能點選畫面上的天體名稱。
- 探索面板可快速篩選「彗星」「小行星」「碎石群」「黑洞」。岩塊保留公尺級實際尺寸，近距離與小天體尺寸改用公尺顯示。
- 開啟時先顯示載入進度，準備貼圖、大氣資料、岩塊與彗星模型及繪圖程式；第一個畫面完成後自動進入。WebGL2 會非阻塞地等待首幀 GPU 工作完成；部分貼圖讀取失敗時改用替代外觀，不會一直等待。
- 按「開啟望遠鏡」進入 10×，雙指縮放或滑鼠滾輪可調整倍率；按「關閉望遠鏡」直接回到 1×，不必逐級切換。望遠鏡只改變視野，不改變天體大小或距離。
- 在畫面上單指滑動可轉向：往下滑看下方、往右滑看右方，與左側搖桿／方向鍵一致。右側按鈕／W、S 前後飛行。手動轉向與前後飛行已調低靈敏度，長按仍會逐漸加速。可轉向接近正上、正下方，避免望遠鏡在極區留下無法指向的範圍。「自由飛行」或 Escape 可解除導航；輸入搜尋文字時不會觸發飛行。
- 自動飛行或跟隨時，單指拖曳、搖桿與方向鍵可直接接手轉向；雙指縮放仍維持跟隨。點過望遠鏡或關閉探索後，鍵盤仍可飛行；新導航會清除上一段觸控狀態。
- 探索面板中的「觀感」提供自然、攝影及固定曝光選項。自然與攝影會調整曝光，並以局部 HDR 色調映射呈現外行星細節；這是顯示近似，不是經校準的人眼或相機模擬，也不改變真實日照的平方反比計算。夜燈不隨局部增益放大。
- 預設維持固定高畫質，保留完整體積解析度與較高採樣，不會因幀率下降自動降低畫質。可自行在探索面板改為均衡或自動；自動模式會依持續的畫面更新速度調整氣體採樣與解析度。實際效能依裝置、解析度與瀏覽器而定。
- 畫面最多每秒提交 60 次繪製，背景分頁停止繪製；回到頁面後依目前日期更新天體。視野外且沒有可見影響的體積效果、黑洞會略過，介面不再逐幀模糊背景。
- 體積背景在輸入相同、或遠處氣體的相對位移極小時沿用上次結果；位移從上次實際繪製累計，避免長途飛行凍結背景。轉向、變焦、材質改變或超過容差時重繪，近景星雲仍採精確比對。微小位移的沿用是顯示近似。
- 只在氣體可能覆蓋的畫面區域繪製體積效果，保留原本的解析度、光線採樣與可見細節。大氣日光路徑表分小段預先計算，避免飛行時集中運算；雲層在畫面上不足以分辨層距時合併計算，接近後恢復分層。
- 星雲在確定沒有發光貢獻的位置略過多餘的照明運算，仍保留塵埃吸收；移除主畫面與體積畫面的重複清除。繪圖環境中斷時暫停提交並清理失效的繪圖緩衝，恢復後重新建立黑洞全天空快取；修正恢復後再改變螢幕尺寸時可能出現的失效資源錯誤。
- 天體隨實際時間運行；不提供日期選擇、暫停或時間快轉。
- 太陽系不顯示行星與衛星的軌道線，公轉仍依軌道模型計算。
- 探索面板的「宇宙音樂」可開關並調整音量，預設關閉，按下播放才會發聲。音樂由 Web Audio 即時生成，不含音檔；一輪約 30 分鐘，結尾無縫接回開頭。切到背景時暫停，回來後繼續。這是藝術化聲景，太空真空無法傳遞聲波，不是太空中錄到的聲音。

## 新增天體與畫面

- 太陽系採橢圓軌道、軌道傾角、近似自轉與衛星潮汐鎖定。加入木星四大衛星、土衛六、土衛二，以及可接近觀察的冥王星。
- 加入穀神星、灶神星和貝努：尺寸、形狀軸長與自轉參數採 NASA/JPL 公開資料，位置使用 2026-10-07 的 Horizons 軌道要素做二體近似。近景岩面、凹坑與貝努表面岩塊是程序示意，不是探測器地形重建。
- 「小行星碎石群（示意）」提供局部碰撞碎石的探索場景，岩塊使用公尺級尺寸；位置、數量、分布與姿態為創作示意，不是觀測到的永久碎石群。真實主小行星帶相當稀疏，既有遠景光點只表示分布，並非放大的實體。
- 新增 67P／楚留莫夫－格拉希門克與 2P／恩克彗星，彗核採公里級實際尺度。可「飛抵天體」近看彗核，或選「退遠看彗尾」移到能看清尾巴方向的位置。彗髮、塵埃尾和離子尾的活動強弱隨日距改變，不保證每個日期都有明亮長尾。
- 新增蓋亞 BH3，與原有五個黑洞共用重力透鏡效果。BH3 是安靜的恆星級黑洞，不加明亮吸積盤或噴流；資料卡區分非旋轉模型的史瓦西半徑與畫面中的黑影。
- TRAPPIST-1 b–h 使用已發表的半徑和週期。比鄰星 b 尚無實測半徑，只顯示位置標記，不繪製假定大小的球體。
- 太陽日照依日距平方反比調整，加入天體相互遮光及土星和環的雙向陰影。遠處太陽以視星等決定光點亮度，與可解析的圓形日面連續銜接；修正約 2,500～4,000 天文單位間不合理消失的區段。眩光只是觀測效果；真空中沒有散射物時，不會出現可從側面看見的光柱。
- 土星環內外緣使用像素覆蓋率抗鋸齒，不改環的實際半徑。穀神星、灶神星與貝努平滑相接頂點的光照法線，避免經線與極點明暗接縫，不改地形或尺寸。
- 恆星近景保留圓形球體、臨邊明暗和表面紋理，周圍有獨立的柔光與放射光芒；從遠處光點到近景平滑銜接。光芒以恆星為中心向外延伸，轉動視角時不會跟著螢幕旋轉。光暈不代表天體直徑，也不改變物理半徑。
- 地球保留地表、夜景、海面反光及大氣，增加多層雲和雲影。月球與火星接近時載入 LOLA／MOLA 實測高程；資料尚未就緒時保留程序地形，資料卡會顯示目前狀態。
- 星雲增加氣體細節和塵埃遮蔽；黑洞可取樣全天空背景，改善彎曲光線離開螢幕後的缺口。
- 天體資料卡區分觀測參數、模型估算及程序示意，並附資料來源。

## 資料與程式來源

- 太陽、行星、月球、土星環的表面貼圖：[Solar System Scope](https://www.solarsystemscope.com/textures/)，CC BY 4.0。貼圖經過重新壓縮與縮放。
- 繪圖函式庫：[three.js](https://github.com/mrdoob/three.js) r128，MIT。
- 黑洞光線追蹤的做法參考 [oseiskar/black-hole](https://github.com/oseiskar/black-hole)（MIT）。
- 大氣散射的算法參考 [wwwtyro/glsl-atmosphere](https://github.com/wwwtyro/glsl-atmosphere)（公有領域）。
- 行星近似軌道：[JPL Approximate Positions of the Planets](https://ssd.jpl.nasa.gov/planets/approx_pos.html)，採用 1800–2050 年公式。
- 月球、主要衛星與冥王星：[JPL Horizons](https://ssd.jpl.nasa.gov/horizons/)，使用 2026-10-07 的軌道要素快照。
- 穀神星、灶神星、貝努：[JPL Small-Body Database](https://ssd.jpl.nasa.gov/tools/sbdb_lookup.html) 的物理參數，以及 [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) 的 2026-10-07 日心軌道要素。[NASA 貝努資料](https://science.nasa.gov/solar-system/asteroids/101955-bennu/)提供表面岩塊的觀測背景。
- 月球地形：[NASA LRO／LOLA LDEM_16 V3.1](https://imbrium.mit.edu/DATA/LOLA_GDR/CYLINDRICAL/IMG/LDEM_16.LBL)，半徑為 1,737,400 + 0.5 × DN 公尺。火星地形：[NASA MGS／MOLA MEGR90N000EB V2.0](https://pds-geosciences.wustl.edu/mgs/mgs-m-mola-5-megdr-l3-v1/mgsl_300x/meg016/megr90n000eb.lbl)，採徑向形狀而非大地水準面高程，半徑為 3,396,000 + DN 公尺。來源屬 [PDS 公共領域資料](https://pds-geosciences.wustl.edu/faq.html)。
- 67P 和 2P：核尺寸來自 [JPL Small-Body Database](https://ssd.jpl.nasa.gov/tools/sbdb_lookup.html) 與 [NASA 恩克彗星資料](https://science.nasa.gov/solar-system/comets/2p-encke/)，位置採 [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) 的 2026-10-07 日心軌道要素快照。67P 的雙葉外形參考 Rosetta 觀測與 [Jorda 等（2016）](https://doi.org/10.1016/j.icarus.2016.05.002)，本程式沒有使用探測器地形網格。
- 蓋亞 BH3：[Gaia Collaboration 等（2024）](https://doi.org/10.1051/0004-6361/202449763)，質量 32.70 ± 0.82 個太陽質量；距離由視差近似換算約 1,926 光年。固定使用 J2017.5 系統質心方向，未推進雙星軌道或自行，非即時精密位置。
- 天體尺寸、週期及物理性質：[NASA Planetary Fact Sheets](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) 與各天體的 NASA Science 頁面；個別來源見資料卡。
- 系外行星：[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/)，2026-10-07 查核。TRAPPIST-1 採 Agol 等（2021），比鄰星 b 採 Suárez Mascareño 等（2025）的資料解。
- 大尺度距離與回溯時間：採參考 [ESA Planck](https://www.esa.int/Science_Exploration/Space_Science/Planck) 參數的平坦 ΛCDM 近似模型，分別積分共動距離和光行回溯時間。

## 哪些是真的

- 太陽系：公開資料中的天體尺寸及軌道參數，位置與自轉為近似計算。衛星採二體軌道，離要素基準日期越久，相位誤差可能越大；不能用來預報精密日月食或掩星。
- 16,166 顆恆星的三維位置與亮度。
- 有名字的星雲、星系、星系團、黑洞的方向與距離（部分座標為近似值）。

其餘的恆星、旋臂上未命名的星雲、宇宙網，是依照真實的分布規律生成的。

未直接測得的恆星半徑可能由亮度和色指數估算。系外行星的表面、部分軌道朝向及相位為示意；未知的海洋或地貌不代表已被觀測。

恆星的放射光芒、日冕形狀和表面亮度壓縮是視覺示意，並非個別恆星的實測影像或完整輻射傳輸模擬。支援深度貼圖時，近景不透明天體會擋住背景氣體；前景星雲與固體之間尚未逐段積分遮擋。

月球與火星實測資料由官方每度 16 格雷射測高格網以 2×2 平均降採樣為每度 8 格（2880×1440）；赤道間距約月球 3.79 公里／火星 7.41 公里。保留實際半徑基準，不誇大高程；原格網含插值，未解析格網以下的細節，也不是逐公尺的探測器地形。地表輪廓仍受即時分級網格的解析度限制，細部明暗另依高程計算。差分與 gzip 壓縮不再損失高度。地形依實際表面經緯度定位，與既有彩色貼圖的精度／配準可能不同。火星大氣與地表相交會參考高程，但大氣密度仍是以平均球面為基準的近似。

兩個正式地形資產合計約 9.97 MB，只在選取天體時預取、前往或接近時解碼並上傳；開場地球不下載它們。解碼分段並排隊進行，背景分頁暫停；每張 GPU 高程貼圖約 8.29 MB，離開再返回可重用。載入失敗或瀏覽器不支援必要功能時沿用程序地形，重新選取可重試，不阻擋航行。

67P 核最長尺度約 4.3 公里，依 Rosetta 約 18.8 立方公里的體積校準，等體積直徑約 3.3 公里。2P 的約 4.8 公里為估計等效直徑，並非已量得的最長邊。程序形狀保留這些尺寸約束，仍不是探測器實測網格；未量得的三軸尺寸、細部地形與旋轉朝向會標示為示意。離子尾採徑向太陽風的反日近似；塵埃尾使用過去釋放的粒子與太陽重力／輻射壓近似，包含軌道遲滯。活動、塵埃參數、尾長和顏色為視覺模型，不是當日量測，未模擬磁場或完整電漿流體。微弱塵尾與離子尾使用固定顯示增益，保留活動及日照造成的相對變化；不隨觀測距離額外增亮，亮度未經實測光度校準。2026-10-07 兩顆分別距太陽約 4.49 和 2.09 天文單位，呈現較弱活動；軌道為二體近似，不能代替精密星曆。

太陽光點採 V 波段絕對星等約 4.83 與距離模數，物理光通量遵守平方反比；最後仍經螢幕曝光、色調映射及小尺寸光點顯示。望遠鏡沿用星表的虛擬增益約定，僅憑倍率不能代表實際口徑與集光力；可見極限不是經校準的觀測儀器。WebGL1 相容模式的 RGBA8 緩衝亮度範圍較小，亮背景可能在色調映射前截斷，降低微弱光點的對比；完整效果以 WebGL2 為準。

地球的雲層是有厚度的分層近似，不是即時氣象，也不是完整的體積雲模擬。星雲三維結構、環散射、黑洞光線積分及全天空快取也有近似；未模擬完整的旋轉黑洞時空。

黑洞光線在外圈補入有限積分範圍外的一階弱場偏折，平滑銜接近場與遠場，改善背景位移接縫；內圈與吸積盤沿用原本積分。這是可互動的顯示近似，並非精密廣義相對論解。全天空背景分批更新，快速移動時仍可能有時間差。

可觀測宇宙的視界不是實體牆。此模型的視界約 460 億光年、宇宙年齡約 138 億年；目前距離不能直接除以光速當成遠方天體的回溯時間。微波背景的彩色球面是示意，不是實際觀測天圖。
